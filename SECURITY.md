# Security Policy

## Supported Version

Siduri does not yet have a tagged release. Security fixes currently target the latest commit on `main`; older snapshots are not maintained.

## Report a Vulnerability

Use the repository's **Security** tab and select **Report a vulnerability** to open a private report. Include affected behavior, reproduction steps, impact, and any suggested mitigation.

Do not include secrets, personal data, or exploit details in a public issue. Allow the maintainer time to validate and coordinate remediation before public disclosure.
